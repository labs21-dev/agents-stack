# Level gate

Four levels. You may climb at most **one** level in a given campaign, and
only with evidence that the current level is already true in the market.

| Level | Sells | Test sentence | Evidence you must already have |
|---|---|---|---|
| **1 Attributes** | spec / function | "This vacuum pulls harder." | A measurable spec the buyer can check. |
| **2 Benefits** | time / money / result | "The house is done; you get the hour back." | A named result with a unit. |
| **3 Identity** | who uses it | "People who run a tight floor use this." | Buyers already say that sentence, or refuse the opposite. |
| **4 Lifestyle / faith** | ritual, default, tattoo | "Not using it would be unlike us." | Queues, marks, holidays, community rules that exist without this campaign. |

Harley tattoos, iPhone queues, Coca-Cola × Christmas are **level 4
exhibits**, not moodboards. Citing them as the look of a launch is a fail
unless the product already has a ritual.

## Honesty rules

1. **Default target = current, or current + 1.** A three-month-old B2B tool
   is level 1 or 2. Writing level 3 copy without identity evidence is a lie.
2. **Level 4 is never a campaign goal.** It is a multi-year residue of kept
   promises. If the user asks to "become a religion / 信仰 / lifestyle
   brand" this quarter, diagnose current level and refuse the skip.
3. **Higher is not better.** A store-manager tool that wins at level 2
   (40 hours → 5 seconds, $20k/store) and stays there is finished marketing.
4. **Do not mix levels in one asset.** An asset that claims spec, identity,
   and faith in 30 seconds is noise. Pick the level of that asset's job.
5. **Community is evidence, not a Slack you will "build later".** Level 4
   `evidence` must name a practice that happens when the company is silent.

## What to write at each level

- **1** — mechanism visible, number on screen, grandma nouns. Same as a
  `plain-sales-copy` unit filmed.
- **2** — the Tuesday after: hours, money, floor time. Still no puff.
- **3** — one in-group / out-group contrast the buyer already uses. Not
  "premium people". A line they would text a peer.
- **4** — do not write ads. Document the ritual. Protect it. Stop selling
  attributes on top of it.
