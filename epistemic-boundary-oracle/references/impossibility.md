# 為什麼萬能預言機不可能

萬能預言機的「萬能」不可能。理由不是工程不足，是認識論封頂。本檔記錄六個限制根源，以及為什麼「加層」不解決任何一個。

## 六個限制

| 限制類型 | 根源 | 例子 |
|---------|------|------|
| 混沌性 | 初始條件敏感依賴，誤差指數放大 | 天氣、金融市場短期波動 |
| 湧現性 | 整體行為 ≠ 個體行為的線性加總 | 群眾恐慌、病毒式傳播 |
| 觀察者效應 | 預測本身改變被預測系統 | 預言公開 → 市場提前反應 → 預言失效 |
| 自我否定預言 | 預言導致行為改變，使預言不成立 | 「明天股市崩盤」→ 今天所有人拋售 → 今天崩盤 |
| 本體論盲區 | 系統無法建模「還不存在的事物」 | 2007 年預測不到 iPhone 改變一切 |
| 計算不可約性 | 有些過程沒有捷徑，必須跑完全程 | 生物演化、社會革命 |

## 為什麼加層不解決

常見的「加層」衝動：加世界模型、加 10^4 agent swarm、加反事實引擎、加強制因果接口、加置信度校準層。這些對第一類域有幫助（那裡本就可校準），但對不可校準域**不改變可預測性**，原因：

### agent swarm 是過擬合放大器

agent-based model 的致命問題不是算力，是**不可校準**。讓一萬個異構代理互動、湧現出恐慌 / FOMO——但無法分辨那是真實湧現，還是寫進代理規則裡的敘事假設的放大。代理數量越多，可調參空間越大，過擬合歷史的能力越強，對未來的預測力**不升反降**。這層把「模型複雜度」誤當成「預測力」。

### Brier 校準有適用邊界

「持續對照歷史預測與實際結果，用 Brier Score 打臉過度自信」只在**可重複預報的域**有效（天氣、日度市場）——恰好是預測已經可行的域。萬能預言機宣稱獨特價值的域（政權更迭、黑天鵝、技術斷裂）是五十年一次、樣本數 = 1。無法用 Brier 校準一個只發生過一次的事件。把可校準域的紀律靜默假定轉移到不可校準域，是校準層最深的漏。

### 觀察者效應的「解決方案」是迴避，不是解決

密封預言 = 沒人能據此行動 = 它不是預言機，是日記。概率雲 = 放棄精確度換實用性。分層揭示 = 把預言機變成權力工具。三件套沒有解決悖論，是把悖論藏起來。真正的問題：任何被行動採納的預言，都與系統糾纏——這不是呈現層問題，是認識論牆。見 `self-reference.md`。

### 強制因果接口漏在預測最重要之處

「物理模組輸出條件 → 社會模組消費條件」聽起來嚴謹。但社會不是被物理條件決定，是被**對條件的信念、敘事、身份認同**決定。接口恰好在「預測最重要之處」漏。沒有社會系統的因果模型，有的是被稱為因果的敘事。

## 設計原則

> 預言機的第一個斷言應該是「我不全知」。

不是「知道一切」，而是「**在認知邊界內做到最優，並對邊界外保持沉默**」。可預測性不是架構層數的函數，是該域是否有預先承諾的邊界 + 足夠同分布樣本的函數。加層不會把不可校準的域變可校準。

誠實版預言機 = 一個會拒絕的路由器 + 一組逐域校準過的窄預測服務。拒絕是預設行為，預測是賺來的特權。它的價值不在「能預測多少」，在「拒絕得有多準」。
