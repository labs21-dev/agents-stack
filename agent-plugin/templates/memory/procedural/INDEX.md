# Procedural memory

Duty: a stable way of acting. Answers "how this should be done."
When to use: when executing a verified procedure instead of guessing the next step.
Purpose: turn rules into a repeatable, verifiable method.
Store: pointers to existing skills / workflows / tests / checklists; short checklists that are not yet a skill (separate files).
Do not store: a copy of a skill body; a one-time success treated as a procedure; the semantic rule itself (that is semantic).
When to update: proven repeatedly, graduate to a skill and keep a pointer here. Invalid, mark `deprecated`.

CRUD lives only in [`../../skills/agent-memory/SKILL.md`](../../skills/agent-memory/SKILL.md). Drawer rule: prefer pointers; do not copy bodies.
