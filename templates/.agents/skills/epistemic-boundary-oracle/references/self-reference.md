# 自指預言（觀察者效應）處理

## 悖論

預言機越準確，就越不準確。公開說「明天某股票漲 10%」→ 所有人買入 → 今天就漲了 → 預言失效。任何被行動採納的預言，都與被預測系統糾纏。

## 三件套是呈現選項，不是解法

| 方案 | 機制 | 代價 | 為什麼不是解法 |
|------|------|------|---------------|
| 密封預言 | 預測寫入時間鎖，到期揭示 | 無法即時行動 | 沒人能據此行動 = 它不是預言機，是日記 |
| 概率雲輸出 | 輸出模糊化（「可能波動」非「漲 10%」） | 降低實用性 | 用放棄精確度換實用性，沒解決糾纏 |
| 分層揭示 | 只對特定決策者揭示 | 權力集中風險 | 把預言機變成權力工具，沒解決糾纏 |

三件套把悖論藏起來，沒有解決。糾纏不是呈現層問題，是認識論牆。

## 真正的處理：分離關注，預測更窄的對象

對「預言會被行動採納」的域（市場、會對預言反應的群體），不預測結果，預測**「在已知系統會對此預言做出此反應的均衡下」的結果**。這是個更窄、可定義的對象：

> 不是「明天股票漲 10%」，而是「若我公開『漲 10%』，在市場會搶跑的均衡下，價格會在 t+1 跳到 X」。

這把預測對象從「與系統糾纏的結果」換成「糾纏機制本身的均衡」——後者是個機制問題，可能落在第一 / 第二類，比前者可校準。

或直接拒絕：若連「糾纏機制的均衡」都不可校準（系統對預言的反應函數本身第三類），則 ⊘ 拒絕 + 「建議保留選項權」。

## 路由規則

1. 判斷預測是否會被行動採納（觀察者效應強度）。
2. 強度低（預測不影響系統，如天氣）→ 正常走三類域分類。
3. 強度高 → 不預測結果，預測「糾纏機制的均衡」。
4. 「糾纏機制的均衡」本身可校準（有重複樣本）→ 走對應類別的機率輸出。
5. 「糾纏機制的均衡」本身不可校準 → 拒絕 / 降格條件式警戒（委派 SDST）。

密封 / 雲 / 分層是這之下的**呈現選項**，在對象已確定為「糾纏機制均衡」後可用於控制二階觀察者效應（對「我會公布均衡預測」的反應），不是處理一階糾纏的手段。
