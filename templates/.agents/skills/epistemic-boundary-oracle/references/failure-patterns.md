# 本 Skill 的失敗模式（自檢）

逐項檢查是否有對應防禦：

- [ ] **越界輸出機率**：對第三類 / 2b / 長視野 2a 輸出了機率分布？防禦 = Hard rule 2/3 + 視野-穩定性閘（協議層拒絕，不是註腳）。
- [ ] **尾巴被抹平**：輸出了單一數字 + 免責註腳？用了註腳式免責 / 不可校準默認成小 / 跨域平均 / 長視野穿短視野衣服任一手法？防禦 = Hard rule 4 + 不可坍縮輸出結構 + `tail-defense.md` 四種抹平手法清單。
- [ ] **2b 當 2a**：把預測者畫的邊界當制度公布的邊界，混進機率路徑？防禦 = `domain-classes.md` 2a/2b 區分 + regime_source 欄（institutional vs analyst-drawn）+ 准入檢查。
- [ ] **長視野穿短視野衣服**：用短視野校準的 Brier 支撐長視野預測？防禦 = 視野-穩定性比自動降級閘（協議層攔截，下游拿不到數字）。
- [ ] **症狀指數當准入用**：用軟改嫌疑指數來**准許**機率輸出，而非只降級？防禦 = 准入與降級分離（`tail-defense.md` 防禦 E）——准入靠 2a + 制度邊界 + 短視野，降級靠症狀。判斷性隔離在降級路徑。
- [ ] **把「不可校準」當「可校準且小」**：因為無法證 P(R 變) 大，就默認 ≈ 0？防禦 = reform_history 標為 descriptive, not predictive；residual 欄標記 uneliminable。
- [ ] **第三方預登記幻覺**：以為獨立第三方預登記域邊界就能補干净事前過擬合？防禦 = `prediction-log.md` 誠實結論：補不干净，第三方面對同一開放問題空間。
- [ ] **加層衝動**：遇到不可校準域，想加世界模型 / agent swarm / 強制因果接口來「提升預測力」？防禦 = `impossibility.md`——加層不改變可預測性，agent swarm 是過擬合放大器。
- [ ] **自指域預測結果**：對「預言會被行動採納」的域直接預測結果？防禦 = `self-reference.md`——預測「糾纏機制的均衡」而非結果，或拒絕。
- [ ] **分類未做就輸出**：跳過域分類直接給機率？防禦 = Hard rule 1 + Flow 步驟 1。分類是 ceiling，分錯全鏈失效。
- [ ] **SDST 委派缺失**：第三類 / 2b / 長視野 2a 降格時，沒有實際委派 SDST 而是空泛「建議考慮條件式警戒」？防禦 = Hard rule 6——委派是路由動作，不是建議。
- [ ] **問題未精確化就分類**：被預測事件「怎樣算發生」都沒說清，就進分類？防禦 = Flow 步驟 0——定義不清先要求釐清。
