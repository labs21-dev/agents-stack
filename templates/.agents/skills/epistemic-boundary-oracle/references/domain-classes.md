# 三類域判準與分類反模式

域分類是整條鏈的 ceiling——分錯類，後面所有輸出形式都錯。分類判準是**域邊界能否在事件發生前被無歧義承諾**，不是「有沒有樣本」。

## 判準

### 第一類 — 邊界由獨立機制釘死

域邊界不是任何人「畫」的，是被物理 / 數學 / 機制**發現**的。預測者沒有判斷空間可過擬合。

- **判準**：存在獨立於預測的機制證據，證明該域的事件共享同一個生成機制。
- **例子**：天氣（大氣物理釘死「地點 + 時間的降水」邊界）、日度市場微觀結構、可重複物理實驗。
- **樣本**：同分布、可大量累積、Brier 有意義。
- **輸出**：機率分布，全窗口。殘餘來自樣本有限，可隨累積消除。
- **預承諾協議的角色**：純記賬紀律（防事後改定義），不是校準來源——因為邊界本來就被機制釘死，沒判斷空間可過擬合。

### 第二類 — 邊界由制度給定

域邊界來自人類制度（央行、選舉法、監管框架）。制度穩定期內可累積樣本，但「制度會不會變」是第三類風險，不可校準。**第二類必須再拆 2a / 2b。**

#### 2a — 制度自己公布了它的邊界

預測者不畫域，制度畫。R 的定義是外部給定的，預測者沒有判斷空間可過擬合（在硬改意義上）。

- **判準**：制度公布了 R 的可觀測定義（使命條文、議事規則、公布頻率、判定口徑），且該定義可被獨立驗證。
- **例子**：Fed 點陣圖、FOMC 會議日程、選舉法規定的選舉日與計票規則。
- **尾巴**：只剩「制度會不會改自己」——單一、可命名、第三類。拆成硬改（觸發線可挂）+ 軟改（殘餘不可消除，見 `tail-defense.md`）。
- **輸出**：機率分布，但**只在窄窗口**（短視野 + 硬改觸發線已挂 + 軟改嫌疑低 + 視野-穩定性比低於閾值），帶置信等級。

#### 2b — 制度存在，但「預測用的域邊界」是預測者畫的

沒有制度定義這個域，是預測者把一群性質不同的事件收進一個桶。

- **判準**：域邊界是預測者事後或事前畫的判斷，不是制度公布的可觀測定義。
- **例子**：「歐洲民粹主義 10 年走勢」「東南亞地緣風險」「AI Agent 種子輪成功率（核心團隊有分散式系統背景子域）」。
- **尾巴**：兩條——制度會變 + 邊界是判斷（後者和第三類同一個病：偽裝成分類的因果假設）。
- **輸出**：**不輸出機率**。降格為條件式警戒，委派 `structural-decision-stress-test`。

### 第三類 — 邊界是事後敘事

域邊界無法在事件發生前無歧義承諾。等事件發生了，才回頭畫邊界把性質不同的事件收攏進同一桶。

- **判準**：無法預先承諾「下一次同類事件長什麼樣」；樣本的同分布性是事後編的。
- **例子**：政權更迭、技術斷裂（iPhone 級）、黑天鵝、進入策略決策（每次承重實體狀態機長得不一樣）。
- **樣本**：樣本數 ≈ 1，就算樣本多也沒用——同分布性本身是事後故事。Brier 無意義。
- **輸出**：**不輸出機率**。降格為條件式警戒（委派 SDST）或拒絕（連條件式警戒都構不出的純混沌）。

## 分類反模式

- **用「有沒有樣本」當判準**。樣本多不等於可校準——第三類域可以靠事後畫邊界湊出很多樣本，但同分布性是編的。判準是邊界能否預先承諾，不是樣本數。
- **把 2b 當 2a**。兩者都「有制度、有樣本」，表面一樣。2a 的邊界是制度公布的（外部），2b 的邊界是預測者畫的（判斷）。混為一談 = 把判斷性偷渡進校準路徑。這是最常見的抹平。
- **長視野當短視野**。第二類的尾巴隨視野放大，長視野下尾巴吃掉主項——長視野第二類是戴著第二類面具的第三類。用短視野校準的 Brier 支撐長視野預測 = 穿錯衣服。視野-穩定性閘（見 `tail-defense.md`）專門擋這個。
- **「聽起來像有制度」就歸第二類**。判準是制度有沒有公布可觀測邊界，不是「這個領域有制度」。有制度但邊界是你畫的 = 2b。
- **把「不可校準」當「可校準且小」**。第三類 / 2b / 長視野 2a 的不可校準是結構性事實，不是「風險很小所以忽略」。無法證大 ≠ 默認為小。
