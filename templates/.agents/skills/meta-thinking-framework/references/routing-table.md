# 問題類型 → 鏡頭路由表

| 問題類型 | 主力鏡頭 | 可省略 |
|---|---|---|
| UI/UX 設計決策 | 底層邏輯 + 心理學 | 經濟學（除非涉及付費轉化）|
| 產品/商業策略定義 | 頂層 + 本質 | — |
| 用戶行為/付費/轉化問題 | 本質 + 逆向 + 經濟學 + 心理學 | — |
| 市場痛點驗證 | 本質 + 逆向 + 經濟學 + 心理學 | 底層邏輯（初期可簡化）|
| 資訊整理/深度研究 | 頂層 + 本質 + 逆向 | 經濟學、心理學 |
| 系統/agent 架構設計 | 底層邏輯 + 逆向（failure pattern）| 經濟學、心理學（除非涉及成本控制/用戶體驗）|
| 人際/團隊協作問題 | 本質 + 經濟學（激勵）+ 心理學（信任）| — |

若問題橫跨多類，取聯集，但仍以「頂層→本質→底層→逆向」為必走骨架。
