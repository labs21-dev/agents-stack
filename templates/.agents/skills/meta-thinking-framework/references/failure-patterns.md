# Agent/系統設計專用：逆向思考檢查清單

設計任何 agent pipeline 或分工架構時，逐項檢查是否有對應防禦：

- [ ] 記憶/上下文失效：目標與約束是否會在多輪對話中遺失？
- [ ] 規格/目標漂移：執行到後期是否可能偏離原始任務？
- [ ] 工具誤用：錯誤的工具調用是否會被誤判為成功？
- [ ] 無限循環：是否設有最大步數/重試次數的安全閥？
- [ ] 靜默失敗：輸出是否有獨立的 verifier 檢查，而非自我宣稱完成？
- [ ] 角色/職責混線：每個子 agent 的輸入/輸出/禁止事項是否明確？
- [ ] 多角色溝通失敗：資訊在角色間傳遞時是否會失真或遺漏？

對每個勾選項，在架構設計中明確寫出對應的 prompt 約束或監督角色。
