# Anti-patterns

1. **Skipping the spec self-check or reverse gate**, then shipping on green
   tests. Not this skill.
2. **Single-metric pass.** "Coverage 100%, complexity 4, ship" without
   mutation cross-check. A single metric never passes.
3. **Grade fixed at step 0.** Discovering L3 reality but keeping L2 gates.
   `feedback-upgrade.md` reopens the grade.
4. **Forcing protocol-adversarial-design on non-protocols.** Its own gate
   STOPs, but only after wasted motion. Delegate on protocol character only.
5. **Suppressing the category disclosure.** It is the skill's boundary, not
   hedging.
6. **Down-grading to dodge work.** L3→L2 only on genuine evidence + real
   reversibility.
7. **Averaging a cross-bucket corner down.** Any L3 corner runs the whole task
   at L3.
8. **Self-declared gate pass.** The verifier is the generator. The coder
   grading its own homework. The verifier must run from a distinct agent /
   refutation-instructed stage (`role-pipeline.md`).
