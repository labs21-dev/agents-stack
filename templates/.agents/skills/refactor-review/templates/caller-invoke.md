## If the caller cannot fill the card yet

```text
Use skill: refactor-review
Generate a provisional specialization card for DOMAIN="<guess>", lint it,
then review at the allowed tier. Mark specialization provisional and list
what I must confirm before L3 Accept.
```

## Expected agent behavior (short)

1. Lint card → label valid/weak/invalid/absent  
2. Grade L1/L2/L3 (bias up if unsure and cost high)  
3. Emit `templates/review-output.md` at required depth  
4. Per major change: Accept / Modify / Reject
